# Stage 6 — Data Analysis

## Analysis areas

### Booking
Demand by date, hour, weekday, weekend, time of day and vehicle.

### Cancellation
Separate:
- customer cancellation
- driver cancellation
- no-driver-found / unfulfilled bookings
- incomplete rides

Calculate rates using clearly defined denominators.

### Revenue
Analyze completed-ride booking value, revenue contribution, average fare and revenue per km.

### Ratings
Analyze observed ratings only; missing ratings are excluded from rating denominators.

### Operations
Analyze VTAT, CTAT, ride distance and location/route demand.

### Statistical analysis
Where appropriate, use descriptive statistics and hypothesis tests. Report effect size/uncertainty where applicable rather than treating statistical significance as business importance.
