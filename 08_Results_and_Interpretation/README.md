# Stage 8 — Results & Interpretation

Each major finding should contain:

1. **Finding** — the observed result.
2. **Evidence** — the table/chart and denominator.
3. **Interpretation** — what the pattern means within this dataset.
4. **Operational implication** — a reasonable action supported by the evidence.
5. **Limitation** — what the data cannot establish.

Avoid causal claims unless the analysis design supports causality.
