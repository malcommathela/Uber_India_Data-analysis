# Stage 5 — Data Aggregation & Representation

## Purpose
Convert the cleaned/engineered dataset into reproducible analytical tables.

Expected tables:
- booking summary
- booking trends by hour/day/month
- cancellation summary
- cancellation by vehicle
- cancellation by reason
- revenue by vehicle/payment/time
- ratings by vehicle
- operational metrics
- location and route summaries

Every table must expose its denominator where a rate is reported.
